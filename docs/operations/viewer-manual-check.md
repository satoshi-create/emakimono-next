# ビューア手動チェックリスト（リファクタリング検証用）

リファクタリング（`EmakiConteiner.js` のフック抽出・UI共通化など）の各ステップで、
**挙動が無変更**であることを確認するための手動チェックリスト。

- 対象: 絵巻ビューア（`/[slug]`）の対話操作
- 前提: `npm run dev` で開発サーバーを起動し、ja / en 両ロケールで確認する
- 実施タイミング: フック1本の抽出ごと・UIコンポーネント抽出ごと
- 失敗したら: 該当コミットを revert し、再度 build + 本リストを通す

## チェック項目

1. **初回ナッジ**: 絵巻ページを開くと自動スクロールが始まり、マウス/ホイール/タッチ/クリックで中断できる
2. **縦→横変換**: ホイールで横スクロール（垂直ホイールが横移動に変換される）
3. **手のひらモード（PC）**: マウス押下で手のひらアイコン + grab カーソル表示、ドラッグでパン、離すと終了
4. **再生モード**: ▶ で自動スクロール開始、停止ボタン / クリック / ホイール / タッチで停止
5. **フルスクリーン位置保持**: フルスクリーン入/切でスクロール位置が保持される
6. **Fキーショートカット**: 絵巻ページでのみ F キーで全画面入/切（入力欄フォーカス中は無効）
7. **向き切替**: portrait ↔ landscape 切替でレイアウトが切り替わり、スクロール位置が保持される
8. **hash同期**: シーン移動で URL hash が更新され、hash 付きURLで開くと該当シーンから開始
9. **巻末ナッジ**: 巻末到達中に次巻カードが表示され、離れると非表示（次巻がある絵巻のみ）
10. **静止UI**: PC 5秒 / モバイル 3秒の無操作で UI 非表示、操作で復帰
11. **スクロールフィードバック**: フィードバックパネルが開閉できる（提出済み絵巻では表示されない）
12. **ナビゲーション**: 先頭へ / 末尾へ / 前後の段ボタンが正しいシーンへ移動
13. **コンソール**: DevTools にエラー・警告がない

## 対象URL例

- `/chouju-giga-first`（鳥獣戯画・初回ナッジ確認）
- `/kusouzumaki`（九相図・巻末ナッジ確認）
- 上記に `/ja` プレフィックスを付けたもの（ja ロケール）
